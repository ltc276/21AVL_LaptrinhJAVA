DETHI JAVA - MENU CHAY 9 BAI LAB

Luu y:
- Noi dung 12 file Java goc (Lab01-Lab09, BSTStudent, ConsoleUtil, Student) duoc giu nguyen.
- Menu.java duoc them de chon va chay tung bai.
- Moi bai duoc chay trong mot tien trinh Java rieng, nen du lieu thay doi khi chay Lab06 khong anh huong lan chay bai khac.

CACH CHAY TREN WINDOWS:
1. Giai nen file ZIP.
2. Mo thu muc DETHI_MENU.
3. Nhan dup file run.bat; hoac mo CMD tai thu muc nay va chay:
       javac -encoding UTF-8 *.java
       java -cp . Menu
4. Nhap so tu 1 den 9 de mo bai tuong ung.
5. Sau khi bai chay xong, menu se hien lai.
6. Nhap 0 de thoat.

CACH CHAY TREN LINUX/macOS:
Mo Terminal tai thu muc nay va chay:
       chmod +x run.sh
       ./run.sh

Neu dung Eclipse:
- Import thu muc DETHI_MENU thanh Java Project hoac copy cac file .java vao src.
- Chay class Menu.java.

Bai 05 va Bai 06 co nhap ID tu ban phim. Cac bai khac tu dong in ket qua.
